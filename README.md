## Project Description

This project is an improved version of my Week 2 personal portfolio website. In Week 3, I enhanced the website using advanced CSS techniques to make it modern, interactive, and responsive.

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* CSS Animations
* CSS Transitions
* Responsive Design
* Git & GitHub

## Features

* Responsive website design
* CSS Grid for project layout
* Flexbox for alignment
* Hover effects and smooth transitions
* CSS keyframe animations
* Interactive cards and buttons
* Mobile, tablet, and desktop responsiveness
* Modern and clean UI design

## CSS Grid & Animations

CSS Grid was used to create a responsive multi-column layout using `auto-fit` and `minmax()`.

CSS transitions, hover effects, and keyframe animations were added to create smooth interactions and improve the overall user experience.

## Responsive Testing

The website was tested on different screen sizes, including mobile, tablet, and desktop, to ensure that the layout remains responsive and does not have horizontal scrolling issues.
